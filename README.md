## 🏥 Selected Work

> Client names are kept private. Projects are described by type and region.

<details>
<summary><b>Realtime patient queues & kiosks</b> — private and public hospitals · West Java</summary>

- **Problem:** Patients waited without knowing when they'd be called, and staff called names by hand.
- **My role:** Built the self-service registration kiosk, queue screens, and voice calling end-to-end.
- **Result:** Live queue screens for registration, clinics, nurses, and pharmacy that update the moment a doctor calls the next patient.
- **Stack:** PHP · Socket.io · JavaScript · PostgreSQL

</details>

<details>
<summary><b>Health insurance & lab integrations</b> — hospitals in West Java and North Sumatra</summary>

- **Problem:** Hospitals must sync claims and medical data with Indonesia's national insurance (BPJS) and health data (SatuSehat) platforms, and exchange orders with lab systems.
- **My role:** Built and maintained the API bridges between the hospital system and each platform.
- **Result:** Doctor mapping and visit letters for BPJS, drug-code mapping for SatuSehat, and two-way lab order and result exchange.
- **Stack:** PHP · REST API · PostgreSQL

</details>

<details>
<summary><b>Multi-hospital rollout & reporting</b> — hospital group · North Sumatra</summary>

- **Problem:** A three-hospital group needed one codebase with site-specific rules, and management needed reliable daily numbers.
- **My role:** Adapted modules for each site and built the reporting layer.
- **Result:** Daily bed-occupancy and cashier settlement reports, plus insurance workflow adjustments, all from one shared codebase.
- **Stack:** PHP · PostgreSQL · FPDF

</details>
